Emberlight is a top-down 2D canvas arena survival game: you are the Lanternkeeper, and your lantern is the only light in a dark arena full of shadow creatures. Drifters chase you, spitters shoot shadow bolts from range, brutes soak up your flares — burn them all back, gather embers, and survive the waves.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, plain ES modules. WASD or arrows to move, mouse to aim, click or Space to cast a flare, P to pause, R to restart.
